วิธีหา **Moon Phase ในดวงกำเนิด** ดูจาก "ระยะห่างเชิงมุม" ระหว่าง **ดวงอาทิตย์กับดวงจันทร์** บนจักรราศี

หลักคิดง่าย ๆ คือ:

> เอาตำแหน่งจันทร์ − ตำแหน่งอาทิตย์
> แล้วดูว่าได้กี่องศาในวง 360°
> จากนั้นเทียบกับช่วง Moon Phase

ในหนังสือ *A Spiritual Approach to Astrology* บทที่ 6 ใช้ Moon Phase เป็นแกนสำคัญในการอ่านจังหวะการตอบสนองของจิตใจ และในบท 13 ผู้เขียนอธิบายเพิ่มเติมว่า New Moon คือช่วงที่จันทร์อยู่ระหว่างโลกกับอาทิตย์ ส่วนจาก New Moon ไป Full Moon คือช่วง **waxing** และหลัง Full Moon กลับเข้าหาอาทิตย์คือ **waning**

## 1. แปลงตำแหน่งอาทิตย์–จันทร์เป็นองศารวม

ให้คิดจักรราศีเป็นวงกลม 360°:

| ราศี        | องศาเริ่มต้น |
| ----------- | -----------: |
| Aries       |           0° |
| Taurus      |          30° |
| Gemini      |          60° |
| Cancer      |          90° |
| Leo         |         120° |
| Virgo       |         150° |
| Libra       |         180° |
| Scorpio     |         210° |
| Sagittarius |         240° |
| Capricorn   |         270° |
| Aquarius    |         300° |
| Pisces      |         330° |

ตัวอย่างเช่น
Sun อยู่ Gemini 3°36' = 60° + 3°36' = **63°36'**
Moon อยู่ Taurus 26°21' = 30° + 26°21' = **56°21'**

## 2. คำนวณมุม Moon Phase

สูตรคือ:

**Moon Phase Angle = Moon − Sun**

แต่ถ้าผลลัพธ์ติดลบ ให้บวก 360°

ตัวอย่าง:

Moon 56°21' − Sun 63°36' = −7°15'
เพราะติดลบ จึงบวก 360°

−7°15' + 360° = **352°45'**

ดังนั้น Moon Phase Angle = **352°45'**

## 3. เทียบช่วงเฟส 8 แบบ

| มุมจันทร์ห่างจากอาทิตย์ | Moon Phase    | ความหมายย่อ                           |
| ----------------------: | ------------- | ------------------------------------- |
|               0°–44°59' | New Moon      | เริ่มต้น สัญชาตญาณ แรงผลักใหม่        |
|              45°–89°59' | Crescent      | หลุดจากเงาเก่า/แพตเทิร์นเก่า          |
|             90°–134°59' | First Quarter | วิกฤต แรงต้าน การตัดสินใจ             |
|            135°–179°59' | Gibbous       | วิเคราะห์ เรียนรู้ ปรับละเอียด        |
|            180°–224°59' | Full Moon     | ความสัมพันธ์ การตระหนักรู้ผ่านผู้อื่น |
|            225°–269°59' | Disseminating | ถ่ายทอด แบ่งปัน เผยแพร่               |
|            270°–314°59' | Last Quarter  | วิกฤตสำนึก รื้อความคิดเก่า            |
|            315°–359°59' | Balsamic      | ปิดรอบกรรม เตรียมสิ่งใหม่             |

ดังนั้นในตัวอย่างด้านบน มุม **352°45'** อยู่ในช่วง **315°–359°59'**
จึงเป็น **Balsamic Moon Phase**

## จำง่ายมาก

ถ้า Moon อยู่ "นำหน้า" Sun ไม่เกิน 180° = ช่วง **Waxing**
คือจันทร์กำลังโต: New → Crescent → First Quarter → Gibbous → Full

ถ้า Moon อยู่เกิน 180° ไปแล้ว = ช่วง **Waning**
คือจันทร์กำลังแรม: Full → Disseminating → Last Quarter → Balsamic → New

## ตัวอย่างจากดวงคุณ

จากข้อมูลที่เคยให้ไว้:

- Sun: Gemini 3°36'
- Moon: Taurus 26°21'

คำนวณแล้วได้ Moon Phase Angle ประมาณ **352°45'**

## Balsamic Moon Phase

เชิงตีความคือ เป็นเฟสของ "การปิดรอบเก่า" ก่อนจะเริ่มวัฏจักรใหม่ คนเฟสนี้มักมีความรู้สึกว่าชีวิตมีภารกิจบางอย่าง สนใจความหมายลึก ๆ ของชีวิต อดีต กรรม จิตวิญญาณ หรือสิ่งที่อยู่เบื้องหลังเหตุการณ์ และมักมีแรงผลักให้เปลี่ยนความต้องการส่วนตัวให้กลายเป็นสิ่งที่มีประโยชน์ต่อผู้อื่น ซึ่งสอดคล้องกับคำอธิบายในบทที่ 6 ว่า Balsamic Moon เกี่ยวกับการเปลี่ยน personal desire ไปสู่ group desires/goals และมีแรงดึงดูดต่อโลกอภิปรัชญา ความหมายชีวิต และอดีต
